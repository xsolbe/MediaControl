# MediaControl 2.1.0

MediaControl now has a Windows installer. Download **MediaControl-Setup-v2.1.0-win-x64.exe** below and run it. The setup adds MediaControl to the Start menu, offers an optional desktop shortcut, and registers an uninstaller in Windows Installed apps. No separate .NET installation is needed.

![MediaControl playback controls](https://raw.githubusercontent.com/xsolbe/MediaControl/v2.1.0/docs/screenshots/playback-en.png)

![Allowed programs](https://raw.githubusercontent.com/xsolbe/MediaControl/v2.1.0/docs/screenshots/programs-en.png)

If you are moving from the portable version, exit it through the tray menu before opening the installed copy. Your settings in `%AppData%\MediaControl\settings.json` remain available. MediaControl still requests administrator permission when launched so its hotkeys can work with elevated games.

## Português

O MediaControl agora tem instalador para Windows. Baixe **MediaControl-Setup-v2.1.0-win-x64.exe** abaixo e execute. Ele cria um atalho no menu Iniciar, oferece um atalho opcional na área de trabalho e pode ser removido em **Aplicativos instalados**. Não é necessário instalar o .NET separadamente.

Ao migrar da versão portátil, feche-a pelo menu da bandeja antes de abrir a versão instalada. Suas configurações em `%AppData%\MediaControl\settings.json` continuam disponíveis. O aplicativo ainda solicita permissão de administrador ao abrir para que os atalhos funcionem em jogos elevados.
