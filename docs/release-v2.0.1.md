# MediaControl 2.0.1

**F9 now pauses or resumes the global media hotkeys from any app or game.** While paused, F1, F2, the volume keys, and seek keys are unregistered, so a game can use them normally. F9 remains registered to bring MediaControl back. The pause state is saved across restarts.

![Hotkeys active](https://raw.githubusercontent.com/xsolbe/MediaControl/v2.0.1/docs/screenshots/playback-en.png)

![Hotkeys paused](https://raw.githubusercontent.com/xsolbe/MediaControl/v2.0.1/docs/screenshots/paused-en.png)

The title bar shows **ACTIVE / PAUSED** and can also toggle the state. The system tray menu offers the same action. Mouse controls in the MediaControl window remain available while hotkeys are paused. F9 is reserved and cannot be assigned to a playback action.

## Download

Download **MediaControl-v2.0.1-win-x64.zip** below, extract it, and run `MediaControl.exe` with PotPlayer installed. The ZIP includes the self-contained Windows executable and licenses. English is the default language; choose Portuguese in **General**.

## Português

**F9 pausa ou reativa os atalhos globais** de qualquer programa ou jogo. Enquanto estão pausados, F1, F2 e as outras teclas ficam livres para o jogo; F9 continua funcionando. O estado de pausa é salvo ao fechar o MediaControl. Você também pode clicar no indicador **ATIVO / PAUSADO** ou usar o menu da bandeja.
