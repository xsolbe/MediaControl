# MediaControl 2.0.0

Control PotPlayer while you play a game or use another Windows app. MediaControl can skip tracks, pause, seek, and adjust PotPlayer volume with global hotkeys. Add games to the program list to make the hotkeys work only while those games are in the foreground.

![Playback controls](https://raw.githubusercontent.com/xsolbe/MediaControl/v2.0.0/docs/screenshots/playback-en.png)

![Allowed programs](https://raw.githubusercontent.com/xsolbe/MediaControl/v2.0.0/docs/screenshots/programs-en.png)

## What's new

- Rebuilt compact player interface based on the `MusicControl.ahk` workflow, with Lucide icons.
- Customizable hotkeys with the original AHK keys as defaults.
- Program allowlist: adding a window or executable enables **Listed only** automatically. Outside the list, keys remain available to the active app.
- **General** page with English as the default language and Portuguese as an option. Changes apply immediately and are saved.
- Minimize to the system tray; click the tray icon to reopen or right-click to exit.

## Download

Download **MediaControl-v2.0.0-win-x64.zip** below, extract it, and run `MediaControl.exe` with PotPlayer installed. The executable includes the .NET runtime and requests administrator permission so the hotkeys also work over elevated games. No separate .NET installation is needed.

## Português

O MediaControl controla o PotPlayer enquanto você joga ou usa outro programa. Baixe o ZIP abaixo, extraia e abra `MediaControl.exe`. Em **Programas**, adicione o jogo: os atalhos passam a funcionar apenas quando ele estiver em primeiro plano. Em **Geral**, selecione **Português**. O botão **−** envia o app para a bandeja do sistema.
